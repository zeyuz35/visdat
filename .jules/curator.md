## 2024-05-24 - Handle nzchar output correctly for multivariate timeseries
**Learning:** `names(x)` can return a character vector of length > 1 for multivariate time series objects (like `mts`). Passing this vector to `nzchar()` produces a logical vector of length > 1. Evaluating a multi-length logical vector in an `if()` condition causes an error (`'length > 1' in coercion to 'logical(1)'`). Furthermore, `nzchar(NA)` evaluates to TRUE. Additionally, assigning names to `df` where the number of names does not match the dataframe width will result in another error.
**Action:** Use `any(!is.na(x) & nzchar(x))` inside the condition to safely evaluate length > 1 logical vectors for multivariate names, and explicitly handle assignment dimension matching by checking `length(names(df)) == length(valid_names)`.
