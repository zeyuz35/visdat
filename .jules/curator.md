## 2025-05-22 - nzchar evaluation bug with length > 1
**Learning:** `names(x)` or `colnames(x)` might return vectors with length > 1 for time-series objects. Evaluating `nzchar(series_name)` directly within an `if()` condition causes a "length > 1 in coercion to logical(1)" error in newer R versions (>= 4.2.0) if `series_name` has length > 1. This error causes execution to halt.
**Action:** When evaluating `series_name` with `nzchar()`, first ensure it has length 1 (or handle multiple lengths properly), then check if the first element is non-empty and non-NA to prevent execution halts or unintended logical evaluations. Use `!is.null(series_name) && !is.na(series_name[1]) && nzchar(series_name[1])` and before that check `if (length(series_name) > 1L) series_name <- NULL`.
