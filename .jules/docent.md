## 2026-05-13 - Initializing Docent Journal
**Learning:** The package requires roxygen2 to update documentation. Rscript might require base R to be installed first. The roxygenise process also needs package dependencies (like ggplot2, dplyr) to be installed.
**Action:** Always ensure R, roxygen2, and the package's dependencies are installed before trying to update the documentation via roxygenise.
